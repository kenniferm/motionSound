# motionSound

自然言語から音を作り、試聴とレビューをもとに改善するMac向け制作アプリです。

開発者向けの検証とPR運用は [GitHubで開発する](DEVELOPMENT.md) を参照してください。

## 起動

Python、uv、Node.js 22.22.2以降とnpm、FFmpeg（Homebrewなら `brew install ffmpeg`）を用意します。Pythonの版は `.python-version` にあります。

`.env.local` に次の値を設定し、`./start` で起動します。起動時に画面をビルドし、Pythonの依存を同期します。ブラウザで <http://127.0.0.1:8501> を開き、停止するときはターミナルで Control+C を押します。設定を変えた場合は再起動します。

すでに起動しているときに `./start` を実行すると、開くURLが表示されます。設定を反映し直す場合は、最初に起動したターミナルで停止してから実行します。

```dotenv
OPENAI_API_KEY="自分のAPIキー"
OPENAI_MODEL="利用できる構造化出力対応モデル名"
# Claudeと聴き比べる場合
ANTHROPIC_API_KEY="自分のClaude APIキー"
# 任意。省略時は claude-sonnet-5-5
ANTHROPIC_MODEL="claude-sonnet-5-5"
# 任意。省略時はプロジェクト内の data/
SOUNDLAB_DATA_DIR="./data"
```

## 制作

1. 中央で指示を入力し、「音を生成」を押すと左の履歴に部屋が追加されます。尺を5〜240秒、候補数を1〜5案から選べます。既定は60秒・1案です。初回は [FABIANの導入手順](FABIAN.md) を参照してください。
2. 右側で完成した候補から試聴できます。下部のプレーヤーで再生や一時停止、波形上の移動、前後の候補への切り替えができます。別の部屋を開いても再生は続きます。候補カードの「制作方針」で設計を確認し、保存された原音・空間設計・アレンジ後の完成版をカードから試聴できます。
3. 「作品の詳細」からレビューを保存できます。「この作品を改善」を押すと中央にその作品の入力欄が開き、結果が同じ部屋に追加されます。

「Claudeでも生成して聴き比べる」をオンにすると、指定した候補数をOpenAIとClaudeのそれぞれで作ります。たとえば1案なら、同じ指示から各1案を作り、同じ部屋に並べます。候補の再開と作品の改善は元の生成元を使います。

新しい完成音源はMP3で保存します。履歴にあるWAVも開けます。

部屋は左の履歴から開けます。「指示を編集」で同じ回を作り直せます。「ひとつ前に戻す」で、やり直す前の指示と音源を復元できます。部屋を削除すると、部屋に属する音源とレビューも削除されます。

失敗時は生成回や候補にエラーと保存地点を表示します。「この候補を再開」で保存済みの段階を再利用できます。

生成したPythonはMacのユーザー権限で動きます。実行にタイムアウトがあり、OSによる隔離はありません。詳細は [構成と運用方針](ARCHITECTURE.md) を参照してください。
